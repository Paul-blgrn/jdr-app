Introduction

Base URL: http://localhost:8000

This documentation aims to provide all the information you need to work with our API.

As you scroll, you'll see code examples for working with the API in different programming languages in the dark area to the right (or as part of the content on mobile). You can switch the language used with the tabs at the top right (or from the nav menu at the top left on mobile).

Authenticating requests

This API is not authenticated.

Endpoints

GET api/user

Example request:
curl --request GET \
    --get "http://localhost:8000/api/user" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json"
const url = new URL(
    "http://localhost:8000/api/user"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

fetch(url, {
    method: "GET",

Store a newly created resource in storage.

Example request:
curl --request POST \
    "http://localhost:8000/api/boards/join" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"code\": \"molestiae\"
}"

const url = new URL(
    "http://localhost:8000/api/boards/join"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "code": "molestiae"
};

fetch(url, {
    method: "POST",

POST api/boards/add

Headers

Content-Type      

Example: application/json

Accept      

Example: application/json

Body Parameters

name   string   

Must be at least 10 characters. Must not be greater than 40 characters. Example: dcwnxxrugnexuxem

description   string   

Must be at least 20 characters. Must not be greater than 70 characters. Example: Consectetur perspiciatis est ipsam illum.

capacity   integer   

Must be at least 2. Must not be greater than 20. Example: 19
